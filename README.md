# 🚀 Team Task Manager

A full-stack task management web application where users can create projects, assign tasks, and track progress with role-based access.

---
##  Live Demo

- Frontend: https://team-task-manager-livid-tau.vercel.app
- Backend: https://team-task-manager-production-60ae.up.railway.app

---
## Tech Stack

### Frontend
- React.js (Vite)
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication

---

##  Features

- User Signup & Login (JWT Auth)
- Create Projects
- Assign Tasks to Users
- Update Task Status (Todo / In Progress / Completed)
- Role-based access (Admin / Member)
- Dashboard with task stats
